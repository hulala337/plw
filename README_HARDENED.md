# V3.2 安全加固版

本版针对“EXE 被二次传播后，别人直接替换版权信息/微信收款码再发布”的场景增加三层防护：

1. **Nuitka 原生编译**：正式版本默认不再使用纯 PyInstaller 方式，而是把 Python 编译成本机二进制并制作 onefile EXE，提高反编译和篡改成本。
2. **Ed25519 完整性校验**：发布时自动生成/复用本地私钥，对版权页、前端 JS/CSS、微信收款码等关键资源生成签名清单；程序启动时验签和 SHA-256 校验，资源被替换会拒绝启动。
3. **Windows Authenticode（可选但推荐）**：配置代码签名证书后，构建脚本会给 EXE 和安装器签名。修改二进制后，原数字签名即失效。

## 私钥

构建脚本默认把私钥保存到：

`%USERPROFILE%\\.pelican_workbench\\signing\\private.key`

这个文件是最高敏感度资产，**绝对不要发送给别人、提交 Git 或放进源码压缩包**。换电脑时应安全备份。

## 现实边界

离线 Windows 软件没有“不可破解”。熟练逆向人员仍可调试、patch 启动逻辑或重新实现客户端。这里的目标是：让普通篡改和低成本二次打包明显更困难，并让正版发布版具有可验证的完整性。

若未来希望更进一步，可以把“版本、作者信息、收款码”做成服务端下发的签名资源，并周期性在线校验；这会牺牲完全离线体验，建议作为可选增强。
