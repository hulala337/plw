# Pelican Workbench Art Direction

## 1. 核心气质

Pelican Workbench 是「温暖、聪明、轻松、有陪伴感的生产力工作台」。

关键词：
- cute but not childish
- premium editorial illustration
- cozy productivity
- soft pastel
- friendly character storytelling
- clean desktop software
- subtle depth
- hand-crafted illustration feeling

## 2. Pelican 主角色

固定角色身份：
- 白/浅灰羽毛
- 柔和蓝灰阴影
- 明亮黄橙色大喙
- 圆润头部与身体比例
- 眼睛简洁、有表情
- 轻微夸张但不能变成卡通贴纸
- 角色体态有真实重量感
- 同一角色不同姿势必须保持头、喙、眼睛、翅膀、身体比例一致

必须建立：
- neutral
- working
- typing
- thinking
- happy
- focused
- tired
- resting
- drinking_coffee
- celebrating
- greeting
- sleeping

## 3. 画面表现

优先：
- 高质量原创数字插画
- 柔和光影
- 细腻材质
- 轻微纸张/笔触质感
- 清晰主体层级
- 有前景、中景、背景空间关系

避免：
- generic AI mascot
- 低质量贴纸
- 纯几何图形
- 过度 3D 塑料感
- 摄影写实
- 不同资产出现完全不同画风
- 随机改变 Pelican 的脸型
- 不必要文字
- AI 乱码文字

## 4. 色彩

基础方向：
- deep navy / blue-gray：导航与深色结构
- sky blue：主交互与积极状态
- warm orange/yellow：Pelican 喙、强调与温暖光
- cream/off-white：插画背景与卡片
- muted green：完成、植物、积极反馈
- lavender/soft purple：次级视觉
- gray-blue：阴影和辅助层

颜色可以随具体场景变化，但不能改变品牌性格。

## 5. 场景统一

办公室场景应共享：
- 同一窗户比例
- 同一桌面语言
- 同一植物/灯具/杯子体系
- 同一城市/水面背景逻辑
- 同一光照方向

天气、时间、季节可以变化，但建筑和核心空间关系不应随机重构。

## 6. 参考图规则

参考图用于：
- 角色身份
- 构图语言
- 色彩气质
- 光影
- 细节密度

不得直接复制第三方作品的独特角色、商标或具体画面。
