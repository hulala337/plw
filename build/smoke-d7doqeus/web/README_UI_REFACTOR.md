# 鹈鹕工作台 V3.3 UI 重构

这是针对现有 `hulala337/plw` 的 UI-only 重构包，目标是把界面从“通用后台 Dashboard”改成你提供的“插画办公室工作台”。

## 已重构

- 左侧深蓝品牌导航 + 鹈鹕办公室插画
- 主区域改为沉浸式横向办公室场景
- 场景内嵌 TO DO / DONE 实物板
- 主视觉右侧增加固定工具栏：待办、鹈鹕状态、开机启动、隐私、设置等
- 指标改为“今日工作评分卡”横向信息带
- Focus Session 与指标同排
- 24 小时时间轴改为全宽
- 首页增加“工作类型分布 / 一周趋势 / 最近 7 天”
- 重做鹈鹕插画，不再使用 `🐦` emoji 作为主要视觉
- 保留现有 API、TODO、设置、回放、统计、天气、时间轴等 DOM ID，尽量不改后端
- 响应式适配 900px / 560px 以下窗口

## 文件

- `web/index.html`
- `web/assets/style.css`

`app.js` 暂不改动，因此现有业务逻辑继续复用。

## 集成

将本目录下两个文件覆盖原项目：

```text
web/index.html
web/assets/style.css
```

然后启动现有项目即可。

## 一个有意保留的后端限制

目前后端字段仍是 `cursor_distance_px`，因此 UI 中鼠标距离暂时继续显示 `px`。如果下一步要完全匹配设计图中的 `km`，需要同时改 `app.py` 的多显示器物理尺寸 / DPI 换算逻辑，不能只在前端把 px 改名成 km。
