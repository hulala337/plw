# 鹈鹕工作台 V3.5 — Art Refinement

## 本轮目标
在 V3.4 完整版基础上继续深化“真实插画场景 + 轻量动态”，不修改业务逻辑、API、数据库、统计计算、TODO CRUD 与回放控制。

## 美术升级
- 角色呼吸、专注、高强度、休息状态独立动画节奏
- 主场景轻微视差与镜头漂移
- 空气尘埃粒子，极低存在感
- 工作状态胶囊提示
- 白板完成反馈改为纸张式回弹
- 角色与环境增加自然投影层次
- reduced-motion 无障碍降级

## 约束
CSS/JS 仅负责资产编排、光照、深度和微动画，不绘制主要角色或办公室主体。

## V3.5 下一轮：角色生命感（Life Layer）
本轮仍为表现层改造，不改变任何业务状态来源。

- 新增透明角色生命层 `pelican-life-overlay.svg`：眼神、眨眼、微表情、头部节奏、翅膀动作、耳机微动、细微动作粒子。
- 新增 `visual-v35-life.css/js`：根据现有 `working / focus-mode / high-intensity / tired / resting / is-idle` 状态编排动作。
- 工作状态会低频随机触发“思考”行为提示，避免机械循环；提示内容只作为视觉表现，不参与业务逻辑。
- 支持 `prefers-reduced-motion`。
