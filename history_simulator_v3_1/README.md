# 《如果我是他们》历史决策模拟器 V3.1

本目录是 V3.1 教学升级层，挂在 `history-simulator-v3.1` 分支中，不修改 Pelican Workbench 主线。

V3.1 的核心升级：
- 把每个历史节点组织为“历史问题—证据—约束—选择—回应—因果解释”。
- 明确“当时信息边界”，不把后来发生的结果倒灌给决策者。
- 增加证据阅读脚手架：observe / source / context / corroborate / decision。
- 增加历史思维评价量规：历史语境、证据使用、因果解释、权衡意识、不确定性意识。
- 增加学生决策单元与教师课堂驾驶信息。
- 保留 V3.0 的 22 个节点、10 个状态维度、多方回应与模拟机制。
- 不加入“反事实实验室”，也不加入此前明确排除的 19—23 扩展功能。

注意：V3.1 是教学结构升级层。正式课堂使用前，应继续对每个节点的具体史实、史料出处、版权/许可和“当时信息边界”逐项复核。
