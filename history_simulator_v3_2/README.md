# 《如果我是他们》历史决策模拟器 V3.2

V3.2 是 V3.1 的史实与史料校准层。重点不是增加玩法，而是把 22 个节点逐项变成可核验的课堂材料。

## 本版完成
1. 规范 22 节点时间轴。
2. 建立史实核验矩阵。
3. 建立一手/二手史料注册表。
4. 建立当时信息边界规则。
5. 建立模型完整性规则，防止把模拟数值伪装成历史事实。
6. 标记史学争议和证据不足处。

## 关键校正
V3.1 曾把“公车上书”作为 1896 年教学占位节点；V3.2 不再采用该占位年份，并将规范时间轴以 canonical_timeline_v3_2.json 固定。

正式课堂版应以 V3.2 的规范时间轴、史实矩阵和来源注册表为准。

## 史料原则
一手材料包括诏令、奏折、报刊、演说、文章、照片、地图、统计和外交文件等；二手材料用于定位、解释和交叉核验。现代教材的总结性判断不得伪装成历史人物原话。历史场景复原图必须明确标注“历史场景复原”。

## 重要来源
Columbia University Asia for Educators 提供洋务、改革、革命及五四时期的原始材料教学入口；包括冯桂芬、严复、梁启超、陈独秀、胡适、孙中山等材料。
Library of Congress 可用于晚清军事与自强运动馆藏定位。
Chinese Text Project 收录《清史稿》等文本，可作为1905年废科举等节点的史料入口。

本版本不加入反事实实验室、此前排除的19—23扩展功能或AI历史解释层。
