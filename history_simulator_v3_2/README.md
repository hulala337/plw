# 《如果我是他们》历史决策模拟器 V3.2

V3.2 是面向课堂使用的完整运行版：在 V3.1 历史思维框架基础上，加入史实与史料校准、当时信息边界、22节点决策、状态变量、多方回应、教师驾驶舱、学生决策报告以及五四空间关系图。

## 已完成
- 22 个规范历史节点（1861—1921）
- 10 个动态状态变量：军事、工业、财政、教育、政治整合、稳定、民族意识、外部压力、体制阻力、社会动员
- 每个节点 3 个可选决策，并明确“没有标准答案”
- 选择后产生资源代价、路径依赖和系统反馈
- 多方行动者回应
- 史实 / 模拟机制 / 教师解释分层
- 当时信息边界：禁止用后来结果倒灌到学生决策时点
- 史实核验矩阵、来源注册表、模型完整性规则
- e18 五四运动空间关系教学图
- 教师驾驶舱
- 学生历史决策报告
- Windows 便携版构建脚本和 GitHub Actions 自动构建

## 运行

### 开发运行（需要 Python）
双击 `start.bat`。脚本会创建 `.venv` 并安装依赖，然后启动 `http://127.0.0.1:52182/`。
也可以运行 `python validate.py` 进行 JSON 和 FastAPI 基础校验。

### 制作免 Python 运行包
Windows 下双击 `build_portable.bat`，会生成 `dist\RuowoshiTamenV32\RuowoshiTamenV32.exe`。
该目录是便携版目录，复制整个目录即可在另一台兼容 Windows 电脑运行，目标电脑不需要预装 Python。首次构建时本机仍需要 Python 和联网安装构建依赖。

### GitHub Actions
`.github/workflows/history-simulator-v3-2-portable.yml` 会在 `history-simulator-v3.2` 分支更新后执行 Windows 构建并上传 `RuowoshiTamenV32-windows` artifact。

## 史料原则
一手材料包括诏令、奏折、报刊、演说、文章、照片、地图、统计和外交文件等；二手材料用于定位、解释和交叉核验。现代教材的总结性判断不得伪装成历史人物原话。历史场景复原图必须明确标注“历史场景复原”。

## 重要校正
V3.1 曾把“公车上书”作为 1896 年教学占位节点；V3.2 已删除这一占位设计，规范时间轴以 `canonical_timeline_v3_2.json` 为准。

- 之前排除的 19—23 扩展功能
- AI 历史解释层

这些不是遗漏，而是按项目要求明确排除。
